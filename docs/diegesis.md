# Diégesis

> [!info] Puntero en construcción
> Hoy este doc es **poco más que una redirección**. `syv-pj` clasifica y entrega al personaje; **no es dueño del lore**. Cuando una hoja necesite contexto del universo —una facción, un lugar, un evento, un nombre canónico— la fuente es **`syv-docs`**, el SSOT de *Subordinación y Valor*, abierto como vault de Obsidian. Acá no se duplica nada de eso. Este doc crecerá cuando haga falta fijar la convención de linkeo personaje↔vault; por ahora, solo redirige.
